互動式 ATR FMC 模擬器

比照你上傳的照片重製的 MCDU 面板 — 點擊鍵盤輸入資料到 SCRATCHPAD（洋紅色那一行）,再按左右兩側對應的 LSK 把資料寫入畫面欄位。純前端教學模擬,數值僅供練習操作邏輯用。

快速上手 / 操作說明
1. 按 MENU 再按右上角 LSK 進入 INIT 頁,輸入 FROM/TO 機場代碼（如 RCSS 松山 → RCFN 台東）。
2. 按 FPLN 建立航線,用鍵盤打航點代碼,再按左側對應 LSK 寫入。
3. 按 PERF 設定 V1/VR/V2 與巡航高度;按 VNAV 看 T/C、T/D 預估;按 PROG 查看剩餘距離與 ETA。
4. 按 MRK 可回到你截圖那種 MARK 頁面樣式;RMS 在此模擬中未實作,僅顯示提示訊息。
5. 右上角 BRT ▲ / BRT ▼ 可即時調整螢幕亮度,跟實機一樣。
6. SCRATCHPAD（畫面最下方洋紅字）打字後,按對應那一列的 LSK 按鈕（螢幕左右兩側灰色小按鍵）即可把資料寫入欄位;再按一次同一顆 LSK 可把欄位內容叫回 scratchpad 編輯。
FMS220 · THALES USER'S MANUAL

Ch.1 SCOPE 筆記

以下是讀完 FMS220 手冊 Chapter 1 · SCOPE（第13–18頁）後,用自己的話重新整理的重點筆記,不是原文逐字翻譯——保留英文關鍵術語（滑鼠移上去可以看中文提示）。每張卡片下方的按鈕會連回原文 PDF 對應頁碼。
1.1

Document overview

  • 這份手冊說明 flight management 的原理、機組員與系統之間的 interface,以及正常與異常情況下的操作/維護程序。
  • 手冊對應的版本很明確:System = FMS220,Program = G6225ABB09,機型 = ATR。
  • 全書共分 8 章:Scope(範圍)、Operational Principles(運作原理)、Pilot Interface(駕駛員介面)、Flight Phase Related Procedures(飛行階段相關程序)、Multi Phase Related Procedures(跨階段共用程序)、Abnormal Procedures(異常程序)、Maintenance Procedures(維護程序)、Glossary(詞彙表)。
白話說:這章是「這本書的使用說明」——先確認你讀的是不是正確的版本(FMS220),再知道整本書怎麼分章節找資料,之後查東西才不會找錯地方。
1.2

System overview

  • FMS 的核心功能包含:多感測器 localisation、flight planning、水平與垂直 guidance、資料庫管理、無線電導航、性能管理與 predictions。
  • 系統組成:一套 FMC 軟體(跑在 IAD 裡)+ 駕駛員介面(雙 MCDU 可輸入,MFD/PFD 只能顯示、不能輸入)+ Compact Flash 資料媒介(載入導航資料庫、次要飛行計畫、磁偏角模型)。
  • 系統有明確的operational domain:
  • 緯度(導航精度保證範圍):S89° ~ N89°;經度不限制
  • UTM/MGRS 座標:緯度限 S80° ~ N84°
  • 最大地速:750 kt
  • 高度範圍:-1500 ft ~ 65000 ft
  • 溫度範圍:-60°C ~ 99°C
白話說:這節最值得背——尤其是那組操作範圍數字,很適合拿來出「輸入超過範圍系統會怎麼反應」這種題型。另外要記住 MFD/PFD 只是顯示螢幕,所有輸入都得靠 MCDU。
1.3

System interfaces

  • 1.3.1 General — 雙套 cockpit 架構,兩顆 FMC 在雙模式下持續同步。座艙開關可設定 reversion 模式:一般狀況下每顆 FMC 用自己那側的感測器,該側失效才自動切對面;但也可以手動選「兩顆都用1」或「兩顆都用2」,此時兩顆 FMC 會被迫共用同一側訊源,就算那側資料無效也一樣。
  • 1.3.2 Air Data Unit — 雙 ADU,提供空速、大氣溫度、氣壓高度;選源邏輯同上。
  • 1.3.3 AHRS — 雙 AHRS,提供姿態角與磁航向,選源邏輯同上。
  • 1.3.4 GPS configuration — 優先用自己那側 GPS,失效才用對面。
  • 1.3.5 Radio navigation architecture — 配置 2 台 VOR、3 頻道 DME、2 台 ADF;兩顆 FMC 都能管理這些接收器,但只有跟自動駕駛耦合的那顆「active FMC」才會真的下指令。
白話說:這節在講「雙套備援」怎麼運作。reversion 這個詞的概念很重要:正常時各用各的、壞了自動切對面;但手動選「都用1/都用2」時就是刻意讓兩顆共用同一側,就算那側是壞的也一樣,這是考試常見的陷阱題。
1.4

Navigation modes

  • 兩種導航模式:BCP(Best Computed Position,預設模式)與 GPS 模式。
  • 兩種模式都會提供:經緯度、地速、航跡角、風速風向。
  • 所有位置運算都以 WGS84 為基準。
  • BCP = 用加權濾波器把 GPS(選定側)與 VOR/DME 訊號融合算出的位置,比單純 GPS 更抗干擾。
  • DR(Dead Reckoning)= 完全沒有地速/位置訊源時的自動備援模式,靠真空速、航向、風去推算位置。
白話說:很多人直覺以為預設是 GPS,其實預設是 BCP——GPS 只是拿來當作 BCP 濾波器裡的其中一個輸入源,不是唯一依據;真的所有訊源都斷了,才會退到用「用速度跟航向硬推」的 DR 模式。
1.5

Conventions

  • 1.5.1.1 Pilot's actions — 手冊寫程序時用三段式標記:IF(前提)、WHEN(時機點)、DO(動作,用粗體)。
  • 1.5.1.2 Cautions, notes and cockpit effect — 斜體 = Note(補充資訊);琥珀色 = CAUTION(警告,提醒錯誤操作的後果);洋紅色 = 這個步驟會影響座艙(COCKPIT effect)。
  • 1.5.2 Supplementary information — 各章給的詳細程度不同:Pilot Interface 章＝「知道就好」的完整介紹;Flight/Multi Phase Procedures＝「必須知道」的精簡步驟;Abnormal Procedures＝完整細節;Maintenance Procedures＝給有資格的維修人員的完整細節。
  • 1.5.3 Foreword — 提醒手冊裡的 MCDU 畫面範例不一定代表實際操作情境;手冊裡的位置一律用地理座標(經緯度)表示。
  • 1.5.4 Terminology — Waypoint 這個詞範圍很廣:不只是資料庫裡真實存在的定位點,也包含 FMC 自己算出來、用來組成航線/垂直剖面的虛擬航點(pseudo/temporary waypoint)。
白話說:這節是「怎麼讀這本手冊」的規則書。重點記兩個:顏色語意(琥珀=警告、洋紅=影響座艙),還有 waypoint 的廣義定義——模擬器 VNAV 頁面的 T/C、T/D 就屬於這種「虛擬航點」,不是資料庫裡真的存在的點。
